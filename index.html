8 ChatGPT Prompt Frameworks
To Help You Master AI

1

R–T–F

R

Role: Specify the role you want the AI to assume.

T

Task: Define the task you want the AI to perform.

F

Format: Indicate the format in which you want the output.

Example:

Role

→

Act as a brand strategist.

Task

→

Write a messeging hierarchyfor a B2B SaaS founder targeting finance teams.

Format

→

Bullet points with core message, value props, proof, and CTAs.

2

S–O–L–V–E

S

Situation: Define the context or situation.

O

Objective: Specify the goals.

L

Limitations: Define any limitations or constraints.

V

Vision: Outline the vision or goal.

E

Execution: Plan the steps for execution.

Example:

Situation

→

You're leading a content team at a startup that just launched a new 825 product.

Objective

→

Generate qualified inbound leads through educational content on Linkedin.

Limitations

→

No ad spend. Small team. Must publish 32/week.

Vision

→

Become the go-to thought leader for mid-market SaaS operations leaders.

Execution

→

Review performance biweekly and double down on top-performing content.

3

T–A–G

T

Task: Define the task at hand.

A

Action: State the action needed.

G

Goal: Clarify the goal to be achieved.

Example:

Task

→

Reduce customer churn in a SaaS subscription business.

Action

→

Analyse churn data and launch a targeted retention programme.

Goal

→

Improve customer retention rate by 15% over the next 6 months.

4

R–A–C–E

R

Role: Specify the character you want the Al to play.

A

Action: State the basic instruction or the job you need to be done.

C

Context: Provide the background information the Al will need.

E

Expectation: Describe the outcome you need.

Example:

Role

→

You are a B2B go-to-market consultant.

Action

→

Build a cold outreach framework including messaging, structure, and CTA.

Context

→

The client sells workflow automation software to mid-size logistics firms.

Expectation

→

Provide 3 email templates tailored to buyer roles (Ops Lend, CTO, Procurement).

5

D–R–E–A–M

D

Define: Define the problem or context.

R

Research: State the research needed.

E

Execute: How to execute the plan.

A

Analyse: How to analyse the results.

M

Measure: Define how to measure the outcomes.

Example:

Define

→

Declining retention in a 128 Saas product.

Research

→

Investigate churn causes through user interviews and CRM data.

Execute

→

Launch a 3-month retention programme with onboarding Improvements.

Analyse

→

Compare behaviour between control and test cohorts.

Measure

→

Track churn rate, product usage frequency, and NPS.

6

P–A–C–T

P

Problem: Define the Problem.

A

Approach: Describe the approach.

C

Compromise: Write about potential compromises.

T

Test: Define the test or measurement.

Example:

Problem

→

Low conversion rate from free trials to paid plans.

Approach

→

Redesign onboarding to highlight core product value within the first 3 days.

Compromise

→

May delay feature rollouts while UX changes are prioritised.

Test

→

Measure conversion rate uplift over a 6-week A/B test.

7

C–A–R–E

C

Context: Give the context.

A

Action: Describe the action needed.

R

Result: Clarify the expected result.

E

Example: Provide an example for clarity.

Example:

Context

→

A SaaS company sees low engagement with its onboarding flow.

Action

→

Redesign the onboarding journey to focus on quick wins and key features.

Result

→

Higher product adoption within the first 7 days.

Example

→

Show how the revised onboarding helped increase day-7 activation from 25% to 42%.

8

R–I–S–E

R

Role: Specify the role.

I

Input: Describe the input needed..

S

Steps: Could you ask for steps to follow?

E

Expectation: Describe the expectation.

Example:

Role

→

Commercial director.

Input

→

Quarterly sales -performance data and pipeline forecasts.

Steps

→

Identify weak points, prioritise high-conversion leads, and optimise resource allocation.

Expectation

→

Deliver a plan to exceed revenue targets in the next quarter.
